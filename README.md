# KURSOR — лист результатов мастер-класса

Страница результатов (2 листа A4), которая подставляет имя и возраст ребёнка из amoCRM по ID сделки в ссылке.

## Как это работает

```
Ссылка родителю                Vercel                        amoCRM
/41335541          →   GET /api/lead?id=41335541   →   GET /api/v4/leads/41335541?with=contacts
                                                    →   GET /api/v4/contacts/{id}
                   ←   { name, age, topic, ... }   ←   кастомные поля контакта
```

Токен amoCRM живёт только в переменных окружения Vercel и в браузер не попадает.

## Формат ссылок

| Ссылка | Что показывает |
|---|---|
| `https://<домен>/41335541` | данные сделки 41335541 |
| `https://<домен>/?id=41335541` | то же самое |
| `https://<домен>/` | статичный демо-текст из разметки |

## Настройка (один раз)

### 1. Токен amoCRM

amoCRM → **Настройки → Интеграции → Создать интеграцию → Внешняя интеграция**:

- название любое, «Ссылка для перенаправления» — `https://<домен>/`, права **Доступ: полный**;
- после создания открыть интеграцию → вкладка **Ключи и доступы** → **Долгосрочный токен** → скопировать.

Токен даёт доступ ко всему аккаунту — хранить только в переменных Vercel.

### 2. Переменные окружения

Vercel → проект → **Settings → Environment Variables**:

| Переменная | Значение | Обязательна |
|---|---|---|
| `AMO_BASE_URL` | `https://kursorschool.amocrm.ru` | да |
| `AMO_ACCESS_TOKEN` | долгосрочный токен из шага 1 | да |
| `AMO_FIELD_NAME_ID` | ID поля «Имя/Имена ребенка» | нет |
| `AMO_FIELD_AGE_ID` | ID поля «Возраст ребенка» | нет |
| `AMO_FIELD_TOPIC_ID` | ID поля «Тема мастер-класса» | нет |
| `AMO_FIELD_MENTOR_ID` | ID поля «Наставник» | нет |
| `AMO_FIELD_DATE_ID` | ID поля «Дата и Время МК» | нет |

Без указанных ID поля ищутся по названию (`Имя/Имена ребенка`, `Возраст ребенка`, `Тема…`, `Наставник`, `Дата…`).
Задавать ID стоит, если в аккаунте есть похожие по названию поля — так надёжнее.

Посмотреть ID полей контакта:

```bash
curl -s -H "Authorization: Bearer $AMO_ACCESS_TOKEN" \
  https://kursorschool.amocrm.ru/api/v4/contacts/custom_fields | python3 -m json.tool
```

После добавления переменных нужен **Redeploy** — Vercel подхватывает их только при новой сборке.

### 3. Проверка

```bash
curl -s "https://<домен>/api/lead?id=41335541"
# {"id":41335541,"name":"Данияла","age":"10 лет","topic":"…","mentor":"…","date":"…"}
```

## Откуда берутся данные

Значение ищется по цепочке: **главный контакт сделки → остальные контакты → сама сделка**, берётся первое непустое.
В карточке из amoCRM имя и возраст лежат в полях контакта (`Имя/Имена ребенка`, `Возраст ребенка`).

Возраст склоняется автоматически: `10` → «10 лет», `11` → «11 лет», `22` → «22 года».
Если в поле уже записано «10 лет», значение берётся как есть.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | разметка обоих листов |
| `styles.css` | стили, формат A4, печать |
| `app.js` | читает ID из ссылки, запрашивает `/api/lead`, подставляет значения |
| `api/lead.js` | serverless-функция: запрос в amoCRM, разбор кастомных полей |
| `vercel.json` | rewrite `/41335541` → `index.html` |

Чтобы вывести на страницу ещё одно поле: добавить `data-amo="ключ"` нужному элементу в `index.html`,
матчер в `FIELD_MATCHERS` и ключ в ответ функции `api/lead.js`, затем `fill('ключ', data.ключ)` в `app.js`.

## Локальный запуск

```bash
npx vercel dev          # со всеми функциями, переменные из .env.local
python3 -m http.server 8080   # только вёрстка, без данных из amoCRM
```

## Печать в PDF

⌘P → «Сохранить как PDF», поля — «Нет», фон и графика — включить.

## Про вебхуки

`integrations.wazzup24.com/amocrm_v2/webhooks/…` — это приёмник событий Wazzup, читать из него данные нельзя.
Данные тянутся напрямую из API amoCRM. Вебхук нужен только если понадобится обратный сценарий —
например, отправлять родителю ссылку на лист в WhatsApp при смене этапа сделки.
